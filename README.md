# U-Tutores

Plataforma web desarrollada como proyecto académico para el curso
**Ingeniería de Software (CC4401)** de la Universidad de Chile.

U-Tutores busca conectar estudiantes con tutores particulares, permitiendo
explorar perfiles, consultar disponibilidad y gestionar reservas de clases
a través de una plataforma web.

## Funcionalidades principales

- Registro e inicio de sesión de estudiantes y tutores.
- Búsqueda y visualización de perfiles de tutores.
- Consulta de disponibilidad mediante calendario.
- Reserva y cancelación de clases.
- Aceptación y rechazo de solicitudes por parte de tutores.
- Perfiles diferenciados para estudiantes y tutores.
- Sistema de calificaciones.
- Historial y gestión de reservas.

## Mi contribución

Durante el desarrollo participé principalmente en funcionalidades
relacionadas con autenticación, usuarios y gestión de reservas.

### Autenticación y usuarios

- Modelado de usuarios estudiantes y tutores.
- Implementación del registro y validación de datos.
- Creación de usuarios y manejo de contraseñas.
- Implementación de inicio y cierre de sesión.
- Desarrollo de funcionalidades del perfil del estudiante.

### Sistema de reservas

- Implementación de la cancelación de reservas.
- Validación en backend para evitar reservas con horarios superpuestos.
- Implementación de notificaciones mediante Django Messages.
- Desarrollo del flujo de aceptación y rechazo de solicitudes de reserva
  por parte de tutores.

### Testing y trabajo colaborativo

- Ejecución de pruebas y corrección de errores.
- Desarrollo colaborativo utilizando Git y GitHub.
- Participación en la planificación y seguimiento del proyecto mediante
  sprints.

## Desarrollo del proyecto

El proyecto fue desarrollado colaborativamente por un equipo de cinco
estudiantes como parte del curso **Ingeniería de Software (CC4401)** de la
Universidad de Chile.

El trabajo se organizó mediante sprints, distribuyendo funcionalidades
entre los integrantes del equipo y utilizando Git y GitHub para el
desarrollo colaborativo.

## Código fuente

El código fuente original se mantiene en un repositorio privado debido a
que corresponde a un proyecto académico desarrollado colaborativamente.

Este repositorio tiene como objetivo documentar el proyecto y las
contribuciones que realicé durante su desarrollo con fines de portafolio.
